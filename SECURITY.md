# Security Policy

## Supported versions

Only the latest commit on the `main` branch is supported. Older commits and
branches are not maintained.

## Reporting a vulnerability

If you discover a security vulnerability in Violet Rally / Set & Slay, please
report it responsibly by email:

- **pantane254@gmail.com**

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce, or a proof of concept.
- The affected URL, route, or component, if known.

Please **do not** open a public GitHub issue for security vulnerabilities, and
do not disclose the issue publicly until it has been addressed.

## Response

Reports are reviewed as soon as possible. You can expect an acknowledgement
within a reasonable time, followed by a fix or mitigation plan. Credit will be
given to reporters who wish to be acknowledged once the issue is resolved.

## Scope

In scope: the Violet Rally / Set & Slay web application and its deployment
configuration. Out of scope: third-party services (WhatsApp, social platforms,
hosting providers) and vulnerabilities in upstream dependencies, which should be
reported to their maintainers.
